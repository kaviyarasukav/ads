# Systematic Quantitative Trading Intelligence Platform

## 📂 Workspace Architecture:

* **[`A/`](file:///z:/ads/A)**: **Current Production & Baseline Quantitative System**
  - Contains all existing backtesting engines (`unified_trade_engine.py`, `risk_management_backtester.py`, etc.).
  - Complete 2026 ETH 5m and 1h market datasets (`eth_market_data.sqlite`, CSVs).
  - 68,202 parameter sweep results (`results/`), charts (`charts/`), and automated test suites (`tests/`).
  - Interactive 6-step quant web terminal (`index.html`, `app.js`, `explorer.html`).

* **[`B/`](file:///z:/ads/B)**: **Future Development Workspace**
  - All new code, advanced algorithms, derivatives feeds (Open Interest, Funding Rates), live execution bots, and next-gen features will be written exclusively here.
